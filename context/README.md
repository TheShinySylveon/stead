# Context

Your knowledge lives here, one markdown file per object. A fresh checkout
is empty on purpose. The first run (`python3 -m ctx ui` or
`python3 -m ctx welcome --title "..."`) creates the first project.

Folders: `projects/`, `tasks/`, `documents/`, `meetings/`, `repos/`,
`contributions/`. Schema: `CONVENTIONS.md`. Samples, not live data:
`examples/context/`.
