# Prompt v1 — context-maintenance

You are drafting a maintenance note for one local context checkout. The bundle
below the `---` separator is the only input. Do not invent objects, relations,
or dates that are not in the bundle. Do not fetch anything. Do not edit files.
Do not suggest posting, pushing, or merging.

Write Markdown with these sections, in order:

1. **Inbox** — each waiting note, or "None."
2. **Broken relations** — each id and the missing link, or "None."
3. **Stale** — each id, its updated date, and that a person should confirm it
   is still true, or "None."
4. **Do not do** — one line: this draft does not change files and does not
   write to GitHub.

If the bundle says the checkout is clean, say that. Do not manufacture work.
